# 🗄️ Thiết Kế Cơ Sở Dữ Liệu Quan Hệ - Relational Database Schema

Tài liệu này đặc tả chi tiết kiến trúc cơ sở dữ liệu quan hệ (Entity Relationship Schema) trong PostgreSQL phục vụ dự án **MyPetClinic**. Toàn bộ lược đồ được thiết kế chuẩn hóa, hỗ trợ xóa mềm (Soft Delete) và tối ưu hóa cho các hoạt động quản lý phòng khám thú y.

---

## 1. Lược Đồ Thực Thể Quan Hệ (Entity Relationship Diagram - ERD)

Dưới đây là sơ đồ thực thể quan hệ biểu diễn sự liên kết giữa người dùng, vai trò, thú cưng, dịch vụ, lịch khám, lịch hẹn, hồ sơ bệnh án, đơn thuốc, vắc-xin, hóa đơn và bài viết:

```mermaid
erDiagram
    ROLES ||--oN USERS : "has users"
    USERS ||--oN PETS : "owns pets"
    USERS ||--oN DOCTOR_SCHEDULES : "has schedules"
    USERS ||--oN APPOINTMENTS : "books/conducts"
    USERS ||--oN POSTS : "writes"
    USERS ||--oN REVIEWS : "reviews"
    USERS ||--oN NOTIFICATIONS : "receives"
    
    PETS ||--oN APPOINTMENTS : "scheduled for"
    PETS ||--oN VACCINATION_RECORDS : "receives vaccine"
    
    SERVICE_CATEGORIES ||--oN SERVICES : "categorizes"
    
    APPOINTMENTS ||--oN APPOINTMENT_SERVICES : "includes"
    SERVICES ||--oN APPOINTMENT_SERVICES : "provided in"
    
    APPOINTMENTS ||--o| MEDICAL_RECORDS : "results in"
    APPOINTMENTS ||--o| INVOICES : "billed in"
    APPOINTMENTS ||--o| REVIEWS : "receives review"
    
    MEDICAL_RECORDS ||--o| PRESCRIPTIONS : "contains"
    PRESCRIPTIONS ||--oN PRESCRIPTION_ITEMS : "prescribes"
    MEDICINES ||--oN PRESCRIPTION_ITEMS : "used in"
    
    VACCINES ||--oN VACCINATION_RECORDS : "administered"
    APPOINTMENTS ||--oN VACCINATION_RECORDS : "recorded during"
    
    INVOICES ||--oN INVOICE_ITEMS : "has items"
```

## 2. Đặc Tả Chi Tiết Các Bảng Dữ Liệu (Detailed Table Schemas)

### 2.1. Bảng `Roles` (Vai trò & Phân quyền)
*   **Mô tả:** Định nghĩa các nhóm quyền truy cập trong hệ thống (Admin, Doctor, Receptionist, Customer).

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Name` | `VARCHAR(50)` | | NOT NULL | Tên vai trò |

### 2.2. Bảng `Users` (Tài khoản người dùng)
*   **Mô tả:** Lưu trữ thông tin tài khoản, mật khẩu và chi tiết cá nhân của người dùng hệ thống.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `UUID` | PK | DEFAULT gen_random_uuid() | Khóa chính dạng UUID tự sinh |
| `Role_id` | `BIGINT` | FK | REFERENCES `Roles`(ID) | Vai trò của tài khoản |
| `Full_name` | `VARCHAR(255)` | | NOT NULL | Họ và tên đầy đủ |
| `Email` | `VARCHAR(255)` | | UNIQUE, NOT NULL | Địa chỉ email duy nhất đăng nhập |
| `Phone` | `VARCHAR(20)` | | NULL | Số điện thoại |
| `Password_hash`| `TEXT` | | NULL | Mật khẩu đã băm bảo mật |
| `Avatar` | `TEXT` | | NULL | Đường dẫn/Base64 ảnh đại diện |
| `Gender` | `SMALLINT` | | NULL | Giới tính (ví dụ: 0: Nam, 1: Nữ, 2: Khác) |
| `Date_of_birth`| `DATE` | | NULL | Ngày sinh |
| `Address` | `TEXT` | | NULL | Địa chỉ thường trú |
| `Is_active` | `BOOLEAN` | | DEFAULT true | Trạng thái kích hoạt tài khoản |
| `Created_at` | `TIMESTAMPTZ` | | DEFAULT now() | Thời điểm tạo tài khoản |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Thời điểm xóa mềm tài khoản |

### 2.3. Bảng `Pets` (Hồ sơ thú cưng)
*   **Mô tả:** Lưu giữ thông tin chi tiết về các thú cưng được đăng ký khám chữa bệnh.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Owner_id` | `UUID` | FK | REFERENCES `Users`(ID) | Khóa ngoại trỏ đến chủ sở hữu |
| `Name` | `VARCHAR(255)` | | NOT NULL | Tên của thú cưng |
| `Species` | `VARCHAR(100)` | | NULL | Loài (Chó, mèo, chim,...) |
| `Breed` | `VARCHAR(100)` | | NULL | Giống thú cưng |
| `Gender` | `SMALLINT` | | NULL | Giới tính thú cưng |
| `Birth_date` | `DATE` | | NULL | Ngày sinh |
| `Weight` | `NUMERIC(5,2)` | | NULL | Cân nặng (kg) |
| `Color` | `VARCHAR(100)` | | NULL | Màu lông |
| `Blood_type` | `VARCHAR(20)` | | NULL | Nhóm máu thú cưng |
| `Sterilized` | `BOOLEAN` | | NULL | Đã triệt sản chưa |
| `Microchip_code`| `VARCHAR(100)`| | NULL | Mã vi mạch định danh |
| `Allergy_note` | `TEXT` | | NULL | Ghi chú về dị ứng |
| `Created_at` | `TIMESTAMPTZ` | | DEFAULT now() | Ngày tạo hồ sơ |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Ngày xóa mềm hồ sơ |

### 2.4. Bảng `Service_categories` (Danh mục dịch vụ)
*   **Mô tả:** Phân loại các dịch vụ tại phòng khám (ví dụ: Khám bệnh, Phẫu thuật, Tiêm phòng, Làm đẹp).

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Name` | `VARCHAR(255)` | | NOT NULL | Tên danh mục dịch vụ |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Thời điểm xóa mềm |

### 2.5. Bảng `Services` (Dịch vụ phòng khám)
*   **Mô tả:** Danh sách chi tiết các gói dịch vụ, giá tiền và thời gian thực hiện dự kiến.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Category_id` | `BIGINT` | FK | REFERENCES `Service_categories`(ID) | Thuộc danh mục dịch vụ nào |
| `Name` | `VARCHAR(255)` | | NOT NULL | Tên gói dịch vụ |
| `Price` | `NUMERIC(12,2)`| | NOT NULL | Đơn giá dịch vụ |
| `Duration_minutes`| `INT` | | NULL | Thời gian ước tính (phút) |
| `Description` | `TEXT` | | NULL | Chi tiết mô tả dịch vụ |
| `Is_active` | `BOOLEAN` | | DEFAULT true | Trạng thái hoạt động |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Thời điểm xóa mềm |

### 2.6. Bảng `Doctor_schedules` (Lịch làm việc của Bác sĩ)
*   **Mô tả:** Đăng ký lịch trực khám của từng bác sĩ thú y theo ngày giờ.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Doctor_id` | `UUID` | FK | REFERENCES `Users`(ID) | Bác sĩ trực |
| `Work_date` | `DATE` | | NOT NULL | Ngày làm việc |
| `Start_time` | `TIME` | | NOT NULL | Giờ bắt đầu trực |
| `End_time` | `TIME` | | NOT NULL | Giờ kết thúc trực |
| `Max_appointments`| `INT` | | NULL | Số lượng ca hẹn tối đa |
| `Is_available` | `BOOLEAN` | | DEFAULT true | Lịch còn trống hay không |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Thời điểm xóa mềm |

### 2.7. Bảng `Appointments` (Lịch hẹn khám)
*   **Mô tả:** Ghi nhận lịch đăng ký hẹn khám của chủ nuôi thú cưng với các bác sĩ.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Pet_id` | `BIGINT` | FK | REFERENCES `Pets`(ID) | Thú cưng khám |
| `Customer_id` | `UUID` | FK | REFERENCES `Users`(ID) | Chủ nuôi đặt lịch |
| `Doctor_id` | `UUID` | FK | REFERENCES `Users`(ID) | Bác sĩ khám |
| `Appointment_date`| `DATE` | | NOT NULL | Ngày hẹn khám |
| `Start_time` | `TIME` | | NULL | Giờ bắt đầu |
| `End_time` | `TIME` | | NULL | Giờ kết thúc dự kiến |
| `Status` | `VARCHAR(50)` | | DEFAULT 'Pending' | Trạng thái lịch (Pending, Confirmed, Cancelled, Completed) |
| `Symptom` | `TEXT` | | NULL | Triệu chứng ban đầu ghi chú bởi chủ nuôi |
| `Note` | `TEXT` | | NULL | Ghi chú thêm |
| `Created_by` | `UUID` | FK | REFERENCES `Users`(ID) | Người tạo lịch hẹn (Lễ tân hoặc Khách hàng) |
| `Created_at` | `TIMESTAMPTZ` | | DEFAULT now() | Thời điểm đặt lịch |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Thời điểm xóa mềm |

### 2.8. Bảng `Appointment_services` (Dịch vụ trong lịch hẹn)
*   **Mô tả:** Bảng liên kết trung gian giải quyết quan hệ nhiều-nhiều giữa lịch hẹn và danh sách dịch vụ đi kèm.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Appointment_id`| `BIGINT` | FK | REFERENCES `Appointments`(ID) ON DELETE CASCADE | Lịch hẹn tương ứng |
| `Service_id` | `BIGINT` | FK | REFERENCES `Services`(ID) ON DELETE CASCADE | Dịch vụ được sử dụng |

### 2.9. Bảng `Medical_records` (Hồ sơ bệnh án)
*   **Mô tả:** Hồ sơ chẩn đoán chi tiết và hướng điều trị do bác sĩ kê sau khi khám xong.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Appointment_id`| `BIGINT` | FK | REFERENCES `Appointments`(ID) | Lịch khám tạo bệnh án này |
| `Doctor_id` | `UUID` | FK | REFERENCES `Users`(ID) | Bác sĩ trực tiếp chẩn đoán |
| `Weight` | `NUMERIC(5,2)` | | NULL | Cân nặng đo lúc khám (kg) |
| `Temperature` | `NUMERIC(4,1)` | | NULL | Nhiệt độ đo lúc khám (°C) |
| `Heart_rate` | `INT` | | NULL | Nhịp tim (bpm) |
| `Symptoms` | `TEXT` | | NULL | Triệu chứng lâm sàng thực tế |
| `Diagnosis` | `TEXT` | | NULL | Kết luận bệnh lý/chẩn đoán |
| `Treatment_plan`| `TEXT` | | NULL | Phác đồ điều trị |
| `Note` | `TEXT` | | NULL | Ghi chú thêm |
| `Follow_up_date`| `DATE` | | NULL | Ngày hẹn tái khám |
| `Created_at` | `TIMESTAMPTZ` | | DEFAULT now() | Ngày tạo bệnh án |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Ngày xóa mềm bệnh án |

### 2.10. Bảng `Medicines` (Kho thuốc)
*   **Mô tả:** Quản lý kho dược phẩm, đơn giá và hạn sử dụng của thuốc.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |
| :--- | :--- | :---: | :--- | :--- |
| `ID` | `BIGINT` | PK | GENERATED BY DEFAULT AS IDENTITY | Khóa chính tự tăng |
| `Name` | `VARCHAR(255)` | | NOT NULL | Tên thuốc |
| `Unit` | `VARCHAR(50)` | | NULL | Đơn vị tính (Viên, chai, ống,...) |
| `Stock_quantity`| `INT` | | DEFAULT 0 | Số lượng tồn kho |
| `Import_price` | `NUMERIC(12,2)`| | NULL | Giá nhập kho |
| `Sell_price` | `NUMERIC(12,2)`| | NULL | Giá bán lẻ kê đơn |
| `Expiry_date` | `DATE` | | NULL | Hạn sử dụng |
| `Description` | `TEXT` | | NULL | Hướng dẫn hoặc chi tiết thuốc |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Thời điểm xóa mềm |

### 2.11. Bảng `Prescriptions` (Đơn thuốc)
*   **Mô tả:** Đơn thuốc chính đi kèm với hồ sơ bệnh án của thú cưng.

| Tên trường | Kiểu dữ liệu | Khóa | Ràng buộc | Mô tả |

| `Doctor_id` | `UUID` | FK | REFERENCES `Users`(ID) | Bác sĩ kê đơn |
| `Note` | `TEXT` | | NULL | Ghi chú dặn dò chung |
| `Created_at` | `TIMESTAMPTZ` | | DEFAULT now() | Ngày kê đơn |
| `Deleted_at` | `TIMESTAMPTZ` | | NULL | Ngày xóa mềm |

### 2.12. Bảng `Prescription_items` (Chi tiết thuốc kê đơn)
*   **Mô tả:** Đặc tả cụ thể từng loại thuốc, số lượng và liều lượng sử dụng trong một đơn thuốc.

| `Medicine_id` | `BIGINT` | FK | REFERENCES `Medicines`(ID) | Thuốc cụ thể |
| `Dosage` | `VARCHAR(100)` | | NULL | Liều lượng dùng |
| `Frequency` | `VARCHAR(100)` | | NULL | Tần suất dùng (ví dụ: 2 lần/ngày) |
| `Duration_days` | `INT` | | NULL | Sử dụng trong bao nhiêu ngày |
| `Quantity` | `INT` | | NULL | Tổng số lượng cấp |

### 2.18. Bảng `Reviews` (Đánh giá dịch vụ)

## 3. Kịch Bản SQL DDL Tạo Bảng (SQL DDL Script)

Dưới đây là mã SQL tạo cấu trúc bảng PostgreSQL chính xác với thiết kế hiện tại của hệ thống:

```sql
-- Xóa các bảng cũ nếu đã tồn tại để tránh lỗi khóa ngoại
DROP TABLE IF EXISTS 
    Roles, Users, Pets, Service_categories, Services, 
    Doctor_schedules, Appointments, Appointment_services, 
    Medical_records, Medicines, Prescriptions, Prescription_items, 
    Vaccines, Vaccination_records, Posts, Invoices, Invoice_items, Reviews, Notifications CASCADE;

-- 1. Create Roles
CREATE TABLE Roles (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Name VARCHAR(50) NOT NULL
);

-- 2. Create Users
CREATE TABLE Users (
    ID UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    Role_id BIGINT REFERENCES Roles(ID),
    Full_name VARCHAR(255) NOT NULL,
    Email VARCHAR(255) UNIQUE NOT NULL,
    Phone VARCHAR(20),
    Password_hash TEXT,
    Avatar TEXT,
    Gender SMALLINT,
    Date_of_birth DATE,
    Address TEXT,
    Is_active BOOLEAN DEFAULT true,
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 3. Create Pets
CREATE TABLE Pets (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Owner_id UUID REFERENCES Users(ID),
    Name VARCHAR(255) NOT NULL,
    Species VARCHAR(100),
    Breed VARCHAR(100),
    Gender SMALLINT,
    Birth_date DATE,
    Weight NUMERIC(5,2),
    Color VARCHAR(100),
    Blood_type VARCHAR(20),
    Sterilized BOOLEAN,
    Microchip_code VARCHAR(100),
    Allergy_note TEXT,
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 4. Create Service Categories
CREATE TABLE Service_categories (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Name VARCHAR(255) NOT NULL,
    Deleted_at TIMESTAMPTZ
);

-- 5. Create Services
CREATE TABLE Services (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Category_id BIGINT REFERENCES Service_categories(ID),
    Name VARCHAR(255) NOT NULL,
    Price NUMERIC(12,2) NOT NULL,
    Duration_minutes INT,
    Description TEXT,
    Is_active BOOLEAN DEFAULT true,
    Deleted_at TIMESTAMPTZ
);

-- 6. Create Doctor Schedules
CREATE TABLE Doctor_schedules (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Doctor_id UUID REFERENCES Users(ID),
    Work_date DATE NOT NULL,
    Start_time TIME NOT NULL,
    End_time TIME NOT NULL,
    Max_appointments INT,
    Is_available BOOLEAN DEFAULT true,
    Deleted_at TIMESTAMPTZ
);

-- 7. Create Appointments
CREATE TABLE Appointments (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Pet_id BIGINT REFERENCES Pets(ID),
    Customer_id UUID REFERENCES Users(ID),
    Doctor_id UUID REFERENCES Users(ID),
    Appointment_date DATE NOT NULL,
    Start_time TIME,
    End_time TIME,
    Status VARCHAR(50) DEFAULT 'Pending',
    Symptom TEXT,
    Note TEXT,
    Created_by UUID REFERENCES Users(ID),
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 8. Appointment Services
CREATE TABLE Appointment_services (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Appointment_id BIGINT REFERENCES Appointments(ID) ON DELETE CASCADE,
    Service_id BIGINT REFERENCES Services(ID) ON DELETE CASCADE
);

-- 9. Create Medical Records
CREATE TABLE Medical_records (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Appointment_id BIGINT REFERENCES Appointments(ID),
    Doctor_id UUID REFERENCES Users(ID),
    Weight NUMERIC(5,2),
    Temperature NUMERIC(4,1),
    Heart_rate INT,
    Symptoms TEXT,
    Diagnosis TEXT,
    Treatment_plan TEXT,
    Note TEXT,
    Follow_up_date DATE,
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 10. Create Medicines
CREATE TABLE Medicines (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Name VARCHAR(255) NOT NULL,
    Unit VARCHAR(50),
    Stock_quantity INT DEFAULT 0,
    Import_price NUMERIC(12,2),
    Sell_price NUMERIC(12,2),
    Expiry_date DATE,
    Description TEXT,
    Deleted_at TIMESTAMPTZ
);

-- 11. Create Prescriptions
CREATE TABLE Prescriptions (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Medical_record_id BIGINT REFERENCES Medical_records(ID),
    Doctor_id UUID REFERENCES Users(ID),
    Note TEXT,
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 12. Create Prescription Items
CREATE TABLE Prescription_items (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Prescription_id BIGINT REFERENCES Prescriptions(ID) ON DELETE CASCADE,
    Medicine_id BIGINT REFERENCES Medicines(ID),
    Dosage VARCHAR(100),
    Frequency VARCHAR(100),
    Duration_days INT,
    Quantity INT,
    Instruction TEXT
);

-- 13. Create Vaccines
CREATE TABLE Vaccines (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Name VARCHAR(255) NOT NULL,
    Manufacturer VARCHAR(255),
    Description TEXT,
    Deleted_at TIMESTAMPTZ
);

-- 14. Create Vaccination Records
CREATE TABLE Vaccination_records (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Pet_id BIGINT REFERENCES Pets(ID),
    Vaccine_id BIGINT REFERENCES Vaccines(ID),
    Appointment_id BIGINT REFERENCES Appointments(ID),
    Doctor_id UUID REFERENCES Users(ID),
    Injection_date DATE,
    Next_due_date DATE,
    Reaction_note TEXT,
    Deleted_at TIMESTAMPTZ
);

-- 15. Create Posts
CREATE TABLE Posts (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Title VARCHAR(255) NOT NULL,
    Slug VARCHAR(255) UNIQUE NOT NULL,
    Thumbnail TEXT,
    Content TEXT,
    Author_id UUID REFERENCES Users(ID),
    Status VARCHAR(50) DEFAULT 'Published',
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 16. Create Invoices
CREATE TABLE Invoices (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Appointment_id BIGINT REFERENCES Appointments(ID),
    Subtotal NUMERIC(12,2),
    Discount_amount NUMERIC(12,2) DEFAULT 0,
    Total_amount NUMERIC(12,2),
    Payment_status VARCHAR(50) DEFAULT 'Unpaid',
    Payment_method VARCHAR(50),
    Paid_at TIMESTAMPTZ,
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 17. Create Invoice Items
CREATE TABLE Invoice_items (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Invoice_id BIGINT REFERENCES Invoices(ID) ON DELETE CASCADE,
    Item_type VARCHAR(50),
    Item_id BIGINT,
    Item_name VARCHAR(255),
    Quantity INT,
    Unit_price NUMERIC(12,2),
    Total_price NUMERIC(12,2)
);

-- 18. Create Reviews
CREATE TABLE Reviews (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Customer_id UUID REFERENCES Users(ID),
    Appointment_id BIGINT REFERENCES Appointments(ID),
    Rating SMALLINT CHECK (Rating >= 1 AND Rating <= 5),
    Comment TEXT,
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);

-- 19. Create Notifications
CREATE TABLE Notifications (
    ID BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    User_id UUID REFERENCES Users(ID) ON DELETE CASCADE,
    Title VARCHAR(255) NOT NULL,
    Content TEXT NOT NULL,
    Type VARCHAR(50),
    Reference_id BIGINT,
    Is_read BOOLEAN DEFAULT false,
    Created_at TIMESTAMPTZ DEFAULT now(),
    Deleted_at TIMESTAMPTZ
);
```
